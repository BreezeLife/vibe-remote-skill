# 语音输入法配置与测试

Vibe Remote 0.2.10 内置 Apple Speech，也提供 Typeless、豆包输入法、Wispr Flow、
Superwhisper、macOS 听写和自定义输入法的配置入口。在「语音输入 → 文字输入位置」
选择文字去向；这个设置独立于识别工具，切换输入法不会改变它。

| 文字输入位置 | 使用方式 |
| --- | --- |
| 先进入 Vibe Remote 草稿 | 保留原有工作区草稿流程，检查后再明确插入和发送 |
| 当前光标所在输入框 | 点击目标文本框，按住说话；结束后填入该处，不按回车、不自动提交 |

旧配置未保存输入位置时，继续使用草稿模式；升级不会自动改成直接输入。
直接输入模式独立保留原来的工作区草稿，不把已有草稿混入本次听写。

内置 Apple Speech 直接接收遥控器音频，不需要虚拟麦克风。第三方输入法通常从
macOS 音频输入设备收音，因此还需要已安装的虚拟音频回环设备：

```text
遥控器 → Vibe Remote → 明确选择的虚拟音频输出
                         ↓ 同一回环设备的输入
                     第三方输入法 → 当前目标输入框
                                    或 Vibe Remote 接收框 → 确认追加草稿
```

安装状态、保存的配置、虚拟设备可见、遥控器已连接，以及实际听写成功是不同的
检查结果。本文中的预设不代表第三方应用已经授权、正在录音或通过实机验收。

## 内置 Apple 识别直接输入

1. 连接遥控器，在「连接与权限」启用语音识别和辅助功能权限。识别语言与允许 Apple
   在线识别的选项仍在「听写」页；默认要求本机识别。
2. 在「语音输入」选择「当前光标所在输入框」和「Apple Speech（内置）」，
   点击「使用内置 Apple 识别」保存。
3. 点击目标应用中可编辑的普通文本框，把光标或选区放好，再按住遥控器语音键说话。
4. 松开后保持该输入位置，等识别完成。Vibe Remote 只填入本次识别结果：有选区时
   替换选区，没有选区时插入光标处。它不发送回车，也不调用编程工具的提交动作。

开始时会记录本次输入位置；填入前再次检查焦点、原有文字和选区。密码框、只读区域
或不能安全替换选区的控件不支持这条路径。期间换了输入框、编辑了原文，或填入结果
无法核对时，不会自动重试；已有识别文字保留在「听写」页，可点击「复制保留文字」。
先核对目标中是否已有本段，再手动处理，最后点击「已核对目标，清空本段」才能开始
下一段，避免重复填入。这里的保留文字与工作区草稿相互独立。

## 第三方输入法首次配置

1. 安装并打开所选输入法，完成其自身要求的账号、麦克风和辅助功能设置。
   豆包输入法与豆包聊天应用是不同产品，请选择实际的输入法应用。
2. 在 Vibe Remote 左侧打开「语音输入」，选择「文字输入位置」和「语音识别工具」。自动发现只读取常用应用目录和输入法目录中的
   应用元数据；发现不了时，可以选择实际的 `.app`。自定义方案可手动选择应用。
3. 在「遥控器音频通道 → 虚拟麦克风」选择已经安装的通道。当前设备列表支持
   MiRemoteV 2ch 和 BlackHole 2ch；这不代表已经验证提供商能从它们收音。
   在第三方输入法里，明确选择对应的同名输入设备。
   输出端和输入端必须是同一条回环路径；Vibe Remote 不会替你更改系统默认声音设备。
4. 先保留「手动：使用输入法自己的快捷键」，并在第三方里关闭自动发送。
   勾选「已在输入法中选择同一虚拟麦克风」；直接输入还需勾选
   「已确认输入法只填文字，不会自动发送（手动触发也需要）」。点击「保存配置」。
   有自动发送开关时先关闭；没有该开关时，依据实际使用行为核对，不能凭空确认。
5. 遥控器语音通道就绪后，点击「准备第三方听写」，按下面所选输入位置完成测试。

### 当前光标所在输入框

1. 准备后，点击目标应用的文本输入框。Vibe Remote 不弹出接收框，也不会替你激活目标应用。
2. 手动模式先用输入法自身快捷键启动录音，再按住遥控器说话；已核对的自动模式直接按住。
   本次输入位置在按住遥控器时捕获，保存配置和点击准备时都不会绑定输入位置。
3. 松开，等待音频送完。手动模式自行结束输入法；自动模式会尝试对应的结束快捷键。
   保持目标输入框，等待提供商完成识别并填入文字。
4. 确认提供商已停止录音、识别完成后，在菜单栏点「输入法已结束，准备下一段」。
   也可回「语音输入」页勾选完成确认，再点「准备下一段」。这一步仅重新准备，
   不复制、不再次插入、不发送；下一次按住时重新检查那时的输入框。
5. 暂时不用或准备手动发送时，在菜单栏点「输入法已结束，关闭本次准备」。修改方案或输入位置前，
   也应先结束本次准备。

直接输入的文字由第三方输入法写入。Vibe Remote 不取回该结果再次插入，也不会将它
自动追加到工作区草稿；更不能把已尝试结束的快捷键当作“输入法确实已停止”的证据。

### 遥控器确认发送（0.2.10）

语音结束仍只填文字。需要用遥控器发送时，先在「编程工具」绑定目标，并完成本次
遥控器独占和按键不穿透验收。在顶部选择「确认发送工作区」，把确认键单击配置为
「预览发送当前输入」或「确认当前输入」（原有默认方案使用同一动作，无需重学键值）。

1. 等豆包停止识别、文字完整出现，选择「输入法已结束，关闭本次准备」。
   「准备下一段」仍锁定听写流程，不能发送。
2. 回到已绑定的目标输入框，短按遥控器确认键。Vibe Remote 读取该框的完整文字并
   打开预览，不重复插入，不使用旧工作区草稿，也不会切到别的会话寻找文字。
3. 核对目标与全文，再按一次确认键发送；返回键取消。实时检查到可用的 Codex
   Steer 时，预览显示「补充当前任务」，确认后使用该控件。

文字、输入框、会话或设备状态改变，正在听写，或预览超时，都会阻止提交。提交结果
不确定时不允许重复按键重发，请到目标应用检查并手动处理。没有绑定工作区时，仍可
跟随光标输入语音，遥控器发送会被阻止。

### 先进入 Vibe Remote 草稿

准备后保持接收框焦点。手动模式先启动输入法，再按住遥控器；松开后等音频送完并
结束输入法。文字完整出现后，勾选「我已确认输入法停止录音、识别完成，文字已全部出现」，
点击「加入工作区草稿」。原工作区草稿保留，本段追加在其后；之后仍用原有的插入、
预览和明确确认发送流程。下一段需重新准备接收框。

「保存配置」只保存设置，不会打开输入法或开始录音。准备时的麦克风、快捷键确认
仅用于本次准备，不写入配置。结束准备后重新准备需要再次核对；直接模式的
「准备下一段」沿用本次方案，但为下一段重新捕获目标。准备、录音和等待完成期间，
工作区与配置保持锁定。

如果没有可用的虚拟音频回环设备，第三方遥控器模式会被阻止；可以继续使用内置
Apple Speech。安装包不包含音频驱动，不会下载驱动、改系统默认麦克风或把声音
临时播放到扬声器作为替代。

Vibe Remote 的音频和接收文字只保留在内存中；第三方输入法有自己的音频、历史记录
和云端处理策略。使用前请在相应应用里核对这些选项。

## 自动快捷键

手动听写测试通过后，可在输入法和 Vibe Remote 中配置**相同**的触发快捷键：

- **按住模式**：遥控器开始收音时按下快捷键；松开遥控器、音频送完后释放快捷键。
- **切换模式**：遥控器开始收音时点击一次；松开、音频送完后再点击一次结束。
- **手动模式**：Vibe Remote 只提供音频路径和输入位置检查，开始/结束由你在输入法中操作。

自动模式使用明确配置的 F13–F20，或带修饰键的空格组合。先在提供商自己的设置里
把快捷键改为该组合，再在 Vibe Remote 中填写，勾选「已设置相同快捷键和触发方式，
并关闭输入法自动发送」。自动快捷键还需要 Vibe Remote 的辅助功能权限，可在
「连接与权限」页启用。不是所有输入法、版本和键盘
都接受同样的按键；不要把建议组合理解为第三方已经设置好的默认值。Fn 和系统麦克风
键的行为因键盘与系统设置而异，本版不模拟这些按键；不能修改时继续使用手动模式。

保存配置不表示快捷键已生效，也无法证明第三方现在已经停止录音。开始前保持所选目标
输入框聚焦；处理期间不要切换应用或工作区。尤其是 Wispr Flow，官方说明文字会插入到
完成时获得焦点的输入框。若发生断开、焦点丢失或第三方异常，先在提供商里确认停止，
再处理已经收到的文字，避免盲目重复开始/结束操作。「中断并检查」会停止本次音频转交，
但不会猜测第三方切换模式的录音状态，也无法撤回它已经填入的文字。停止转交并不能保证
第三方不再处理已缓存的音频；释放按住式快捷键也可能触发其最终填入。先手动检查提供商
与目标，再确认完成或关闭准备。不要在结果尚未出现时切到另一个输入框。

## 各提供商设置位置

以下来自官方文档，核对日期为 2026-10-12；请以本机安装版本显示为准。

| 提供商 | 官方触发方式与设置入口 | 输入设备 |
| --- | --- | --- |
| Typeless | Dictate 默认点击 Fn 开始，再点击结束；Settings → Keyboard shortcuts 可修改或添加快捷键 | Settings → Audio → Microphone 指定设备 |
| 豆包输入法 | 官网提供 macOS 版；本机输入法中核对语音触发方式，不沿用豆包聊天应用设置 | 在本机版本中核对麦克风选项；若不能指定所需设备，保留为待验证 |
| Wispr Flow | 默认按住 Fn、松开结束；无 Apple Fn 的 Mac 使用 Ctrl+Option；Settings → General → Shortcuts 可修改 | Settings → General → Microphone → Change |
| Superwhisper | Settings → Configuration：Toggle Recording 默认 Option+Space；另有 Push to Talk，短点也可能进入切换录音 | Settings → Sound → Input Device |
| macOS 听写 | 系统设置 → 键盘 → 听写：自定义开始/停止快捷键 | 同处的麦克风来源 |
| 自定义 | 选择实际应用，核对其支持的按住/切换方式；默认手动触发 | 必须确认所选输入能收到该回环输出 |

Typeless、Wispr Flow、Superwhisper 和系统听写的官方资料说明了音频设备选择，
但没有保证某个特定虚拟驱动与每个版本都兼容。必须完成下方实际收音测试。

### 本机豆包 0.5.7 的设置入口

2026-10-15 实际设置窗口显示：麦克风可明确选择 **MiRemoteV 2ch**；快捷键为 **Ctrl**，
长按说话、松手结束，也支持双击进入免按模式。本机系统听写同样绑定双击 Ctrl，初测
先用长按，避免两套听写同时触发。Vibe Remote 保持手动模式，不模拟单独的 Ctrl。

豆包的后台输入法本体没有设置窗口；本机独立设置应用位于
`/Library/Input Methods/DoubaoIme.app/Contents/DoubaoImeSettings.app`。
该版本完整设置页未显示自动发送开关；用户确认日常语音文字留在聊天输入框等待手动发送。
这与实测遥控器回环转写是两项验收，后者仍须按下方流程完成。

## 测试步骤

使用不含隐私的短句，例如“这是遥控器语音测试”，并逐项观察：

1. **输入法自身测试**：先完成第三方自己的新手测试，确认账号、授权和快捷键可用。
   之后按上文选择虚拟麦克风和输入位置。内置识别直接模式可跳过第三方与回环检查。
2. **遥控器音频**：按住语音键时，Vibe Remote 音量和样本计数实际变化；松开后停止。
   蓝牙已配对或设备出现在列表里，不能替代这一步。
3. **回环路径**：在输入法中选对应虚拟麦克风。只有对着遥控器说话时出现真实电平和文字，
   才能确认没有误用 Mac 自带麦克风。不要通过修改系统默认设备掩盖配置错误。
4. **输入位置与两次短句**：在无重要内容的文本框中先放光标，再试选中部分原文，
   分别观察插入和替换是否正确。内置识别只填入本次结果；第三方直接模式每段明确确认
   完成后再准备下一段，不应重复填入。草稿模式应先等待确认，再追加到工作区草稿。
5. **自动触发**：启用已核对的快捷键后，再做两次短句；观察提供商真实开始和结束，
   不以 Vibe Remote 显示“已发送快捷键”代替。
6. **保留与发送**：草稿模式已有原文时再听写，确认原文保留；直接模式不应修改工作区草稿。
   两种模式都不能因为松开语音键就在编程工具中自动提交消息。
7. **故障恢复**：在没有重要文字的一次测试中断开遥控器，或让所选虚拟设备不可用。
   确认不会回退到扬声器或其他麦克风，也不会自动发送。检查第三方是否仍录音，必要时
   手动结束，然后重新核对设备、目标焦点和触发方式。内置直接输入还应在测试时更换
   焦点或编辑原文，确认停止填入、保留识别结果，并且不会自行重试。

## 常见问题

| 现象 | 检查与处理 |
| --- | --- |
| 显示已安装，但没有文字 | 安装只代表找到应用；检查提供商本身是否运行、授权、完成设置，以及真实录音状态 |
| Vibe Remote 有电平，输入法没电平 | 核对回环输出/输入是否对应；输入法仍可能选择了其他麦克风 |
| 检测不到豆包输入法 | 不选择豆包聊天客户端替代；确认实际输入法安装位置，重新选择其应用 |
| 自动按键没有反应 | 先回到手动模式；核对两边快捷键完全一致、提供商支持该组合、权限已授予 |
| 松开后第三方仍录音 | 可能是模式不一致、焦点/快捷键失效或第三方状态变化；先手动结束，避免反复切换 |
| 文字落到其他应用 | 先停止第三方并检查实际输入位置；已填入内容需手动处理，Vibe Remote 无法撤回第三方写入 |
| 内置直接输入保留了本段文字 | 先检查目标是否已有内容；可复制文字自行处理，再清空本段，避免重复输入 |
| 虚拟设备不见了 | 阻止第三方遥控器模式，恢复设备后重新选择；不会自动更换系统声音配置 |
| 不确定是否已输入 | 直接模式先检查目标，草稿模式对照接收框与草稿；不确定时不重复填入或提交 |
