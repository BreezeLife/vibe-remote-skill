# Vibe Remote app icon

Created on 2026-10-08 using the built-in image_gen tool for the user's app-icon request.
The design combines a warm-white handheld remote with a mint voice waveform on a dark
graphite rounded-square tile. No third-party logos or reference artwork were used.

`AppIcon.png` is the unmodified generated source (1254 × 1254, RGBA). Transparent corners
are preserved. `../AppIcon.icns` contains standard macOS 16–1024 pixel representations.
Regenerate the ICNS with `bash scripts/build_macos_icon.sh` from the repository root.
This performs only resizing/format conversion using macOS sips and iconutil; no API call
or image-generation account is required to build the app.

## Generation prompt

Use case: logo-brand. Asset type: a finished macOS desktop app icon for Vibe Remote, an independent voice coding app controlled with a physical remote. Create ONE polished, distinctive icon, 1024 x 1024 square. A large dark graphite rounded-square app tile, front-facing and centered, with genuinely transparent corners and a small transparent outer margin. Center one sculpted warm-white handheld remote control, vertical with a very slight playful diagonal tilt, occupying most of the tile height. The remote is a broad simple capsule with a dark recessed central panel containing exactly five bold mint-teal vertical rounded audio waveform bars, a small round control above, and one small circular button below. Fuse remote control and voice recording into one instantly legible silhouette. Use restrained tactile dimensionality, a gentle bevel and soft internal shadows, crisp clean edges, premium understated macOS utility-app craft, strong contrast readable at 32px. Keep the composition simple and generously sized, no tiny details. No typography, no letters, no brand logos, no sparkles, no external objects, no mockup or desktop scene, no grid or variants, no perspective platform, no cast shadow outside the tile. The result itself is the ready-to-use icon with real alpha outside its rounded-square silhouette.
